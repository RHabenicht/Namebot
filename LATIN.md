# Roman Latin names

This starter set uses Roman citizen naming patterns from the first and second centuries CE. Select the program for the order you want.

| Program | Order | Possible combinations |
| --- | --- | ---: |
| `roman_male` | praenomen + nomen + cognomen | 7,680 |
| `roman_female` | nomen + cognomen | 480 |

The nomen is the inherited clan name. The cognomen is a byname that can also mark a family branch. Each program draws from its own component pools to keep the correct order.

The 60 masculine elements come from Ursula Georges’s lists. The 44 feminine elements use the regular final `us` to `a` pattern. The source records mark the derived forms and use Iulius and Iulia consistently.

The program selects each component with equal probability within its pool. The combinations are fictional. The source lists cover the name elements and their roles.
