# Roman Latin names

This resource replaces the rejected mixed Latin import. It targets Roman citizen naming patterns in the first and second centuries CE. It is a curated starter collection.

| Profile | Order | Possible combinations |
| --- | --- | ---: |
| roman_male | praenomen + nomen + cognomen | 7,680 |
| roman_female | nomen + cognomen | 480 |

Use the profile's program entrypoint. Do not route this resource through a generic given-name/surname formatter. Components belong to separate gendered pools. The nomen is the inherited clan name; the cognomen is a byname that can also identify a family branch.

The 60 masculine elements are selected from Ursula Georges's lists. The 44 feminine elements are grammatical derivatives using the regular final `us` → `a` pattern. Each record marks this distinction. Derivation does not establish an individual historical attestation. Spelling uses Iulius/Iulia consistently.

Full combinations are fictional. Uniform selection provides variety for a game; it does not reproduce historical name frequencies, family-specific praenomina, or membership of documented family branches. These profiles do not cover every Roman social status or naming period.

Sources:

- [Ursula Georges, A Simple Guide to Imperial Roman Names](https://yarntheory.net/ursulageorges/names/roman.html): element lists and feminine formation.
- [Barbara F. McManus, Roman Nomenclature](https://vroma.org/vromans/bmcmanus/roman_names.html): roles of the name components and variation by status and period.

Source URLs and derivations are also recorded in JSON. The rejected Latin source is not included in this bundle.
